# Run Configs

This directory holds assembled run-specific configuration sets.

Current contents:
- `runs/2019/settings.yaml`
- `runs/2019/controls.csv`
- `runs/2020/settings.yaml`
- `runs/2020/controls.csv`
- `runs/2022/settings.yaml`
- `runs/2022/README.md`

The 2022 control CSV is expected to be generated by the prep workflow and staged alongside the run before execution.

The legacy flat `configs/` files still remain active for backward compatibility during migration.

Example command pattern:
```bash
python scripts/run_popsim.py \
  -c configs/runs/2020 \
  -c configs/base \
  -d data/2020_census_blkgrp \
  -o outputs/2020 \
  -s settings.yaml
```
